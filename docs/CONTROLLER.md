# Controller menu controls

The D-pad and right stick navigate; A accepts and B goes back. The left stick
moves the pointer and makes A click. Using the D-pad or right stick returns to
navigation. Start opens/closes the Escape menu during gameplay.

On the main menu, Left/Right wraps through the loaded movie's visible groups
in their authored horizontal order. Up/Down chooses that group's visible entries.
RotWK and BFME2 therefore retain their own campaign choices and hero-button
spelling; the same discovery applies to BFME1 and modified menus. A opens the
group or activates its authored button action, using the native menu highlights.

On result screens, A skips the preview, then focuses More or Continue. B returns
from details through the normal result-screen actions.

## Skirmish lobby

Start starts the game from the main skirmish page through its normal start checks;
profile dialogs cannot launch the match.
LB/RB switches between Maps and Rules. The D-pad moves between controls,
favoring controls aligned with the current row or column. Map lists use Up/Down
to browse maps. For a closed dropdown, directions move focus without changing
the setting. Press A to open it, Up/Down to preview a choice, then A to confirm.
B cancels the preview. Changing tabs also cancels an unconfirmed dropdown.
This includes the player-color image dropdowns.

In the skirmish lobby, LT cycles Bottom Bar → Players → Maps/Rules; RT cycles backward.
Thin corner accents in the native menu palette mark the active area.
D-pad/right-stick navigation stays within it; triggers cancel an unconfirmed
dropdown before changing area. Mouse movement and real keyboard input leave
section mode, retaining their existing navigation. Modal profile dialogs remain
fully navigable. LB/RB still changes Maps/Rules.

A controller is claimed by a button press or axis input beyond the dead zone.
Drift and releases from unused controllers cannot claim it. A button press on
another controller safely releases the old controller's held menu input before
handoff.

Menu input leaves gameplay events available when no menu is active. Releases
belonging to an earlier menu press stay consumed across a menu-to-game transition.

Network and online staging lobbies use the same LT/RT section cycle. LB/RB
cycles Maps, Rules and Chat within the shared panel. Native Escape-menu
navigation uses the same D-pad/right-stick, A and B mapping.
