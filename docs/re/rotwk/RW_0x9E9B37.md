## Scan and arithmetic

RW 0x9E9B73..0x9E9C89 builds a PartitionFilter::And chain and calls
PartitionManager::iterateObjectsInRange(caster.position, radius, 0, filters,1)
(RW 0xA39340, BFME2 BfmeWideResultForward.cpp). Order 1 is the current port's
near-to-far query order. The filters are:

* alive: vtable RW 0xC10E20, predicate RW 0x660E71, Object +0x458 bit 0 clear;
* exclude any template kind in bit set {7,91}: copy RW 0x9E9AE1,
  vtable RW 0xC110A4, predicate RW 0x660E4A;
* include any template kind in bit set {3,90}: copy RW 0x9E9B0C,
  vtable RW 0xC309B4, predicate RW 0x660DC6;
* relationship mask 6 (allies or enemies, not neutral), vtable RW 0xC1676C,
  predicate RW 0x66110A; player RW 0x68B678.

The map's Waypoint::addLink label for RW 0x672645 is a misleading similar
body: here it constructs a filter. Keep numeric kind bits until their layout
is reconciled. `BfmeWideResult::next` is RW 0x444F19; destructor RW 0x44A2A5.

Constants read from the image: RW 0xC8E360 double 2/3,
RW 0xBD869C float 0.5, RW 0xBD8698 float 4294967296,
RW 0xC8E338 float 2, RW 0xC8E33C float 0.6499999761581421.

Grid cell width is `__ftol2(x87(radius * double(2/3)))`, **not** radius,
and not a float32 2/3 multiply. Grid origin is caster.xy minus radius, z
unchanged. Coordinates are first float32-subtracted, then CVTTSS2SI, then
signed integer-divided by cell width. There is no clamp or zero-width guard.
The result addresses nine int32 cells as x*3+y. An engine port must establish
the query's boundary invariant rather than silently clamp out-of-range hits.

For each hit, the bitflag-any call at RW 0x9E9D11 checks the **caster's**
Object +0x1C8, not the hit's. A set flag skips all accounting for that hit.
ALLIES=2 via Player::getRelationship(Object*) (RW 0x6ADC43,
PlayerGetRelationship.cpp) determines the two grids. Costs are two independent
RW 0x73C25F(template,0,0,-1) calls per hit; that null-player path returns the
template's unsigned-short build cost from its final override (+0x5EA).
The first adds full cost to the grid. The second adds to the unsigned total,
except template +0x123 bit 2: x87 signed(cost)*0.5 + unsigned(total), ftol2.
That flag's semantic name is **INFERENCE** until the kind layout is proven.
Allied body metrics accumulate with x87 FADD and FSTP float after every hit.

## Recovered control structure

Descriptive adapters below are not asserted original symbols. `x87` denotes
the engine's retail precision-control arithmetic, not host long double;
`add32/sub32` wrap, `signed32` reinterprets the bits. SSE operations are separate
float32 steps. Registry and filter adapters are deliberately explicit gaps.

```cpp
Bool SoulFreezeDecision::decide(Object *caster)
{
    // RW 0x9E9B4A..0x9E9C89
    Team *team = caster->team;
    Object *registered = team->lookupPower(power, 0); // RW 0x7A3EF5
    if (registered && registered != caster) return false;
    auto hits = scanWithFilters(caster, radius, {7,91}, {3,90}, 6);
    if (hits.empty()) return false;
    // RW 0x9E9C8F..0x9E9E44
    int32 allied[3][3] = {}, other[3][3] = {};
    uint32 aTotal = 0, oTotal = 0;
    float metric = 0;
    Coord3D origin = {subf(caster->x,radius), subf(caster->y,radius), caster->z};
    int width = ftol2(x87mul(radius, double(2.0/3.0)));
    while (Object *o = hits.next()) {
        if (caster->flags1C8.any()) continue;
        int x = cvtt(subf(o->x,origin.x))/width;
        int y = cvtt(subf(o->y,origin.y))/width;
        bool ally = caster->player()->getRelationship(o) == ALLIES;
        if (ally) metric = fstpf(x87add(o->body->slot14(), metric));
        auto &cell = ally ? allied[x][y] : other[x][y];
        auto &total = ally ? aTotal : oTotal;
        cell = add32(cell, o->thingTemplate->getBuildCost(0,0,-1));
        int cost = o->thingTemplate->getBuildCost(0,0,-1);
        if (o->thingTemplate->flag123(4))
            total = ftol2(x87add(x87mul(cost,0.5f), unsignedToX87(total)));
        else total += uint32(cost);
    }
    if (!oTotal) return false;
    // RW 0x9E9E55..0x9E9F68
    bool useDifference = unsignedToX87(oTotal) > x87add(unsignedToX87(aTotal),
                                                       unsignedToX87(aTotal));
    if (!useDifference) useDifference = hasCurrentVictim(caster); // RW 0x9930A3
    int x=1, y=1, best=0;
    if (useDifference) {
        for (int i=0;i<3;++i) for (int j=0;j<3;++j) {
            int d=sub32(other[i][j],allied[i][j]);
            if (d>best) { best=d; x=i; y=j; }
        }
        useDifference = orderedGreaterEqual(float(other[x][y]),
                                             mulf(float(allied[x][y]),2.0f));
    }
    // RW 0x9E9F68..0x9EA039
    if (!useDifference) {
        if (!(metric < 0.65f)) return false; // includes unordered rejection
        x=1; y=1; best=0;
        for (int i=0;i<3;++i) for (int j=0;j<3;++j) {
            int sum=add32(other[i][j],allied[i][j]);
            if (sum>best) { best=sum; x=i; y=j; }
        }
    }
    // Deliberately radius spacing, NOT the width used for binning!
    Coord3D target={addf(mulf(float(x),radius),origin.x),
                    addf(mulf(float(y),radius),origin.y),origin.z};
    if (!rva005EE8DD(&target,caster)) return false; // RW 0xA0229F
    team->registry.push_back({power,TheGameLogic->getFrame(),0,0,caster->id});
    return true;
}
```

Both max searches initialize the winning cell to (1,1) and update only on
strict signed `>`; ties keep the first strictly positive winner in x-major
order. The local grid-to-float conversion is signed, unlike the global-total
x87 comparison. The first branch failing target validation does not try the
second branch. RW 0xA0229F is the same-shape donor Rva005EE816::rva005EE8DD in
AISPecialPowerTargetAoE.cpp: validates/stores the position, optionally searches
along a randomly chosen direction. Thus this decision has indirect RNG when
target validation requires search, although no direct draw occurs here.
