## Recovered C++

```cpp
// RW 0x8B708B..0x8B70DA; names agree with the current port.
Bool AISpecialPowerUpdate::powerReady(const SpecialPowerTemplate *power)
{
    Object *object = m_object;
    if (object->testStatus(90)) return false; // IS_LEAVING_FACTORY
    if (!TheSpecialPowerStore->canUseSpecialPower(object,power)) return false;
    SpecialPowerModuleInterface *module = object->getSpecialPowerModule(power);
    if (!module) {
        m_active = false;
        return false;
    }
    return module->isReady();
}
```

Every branch returns a boolean in AL. Leaving-factory and permission failures
do **not** deactivate the AI module. A present but unready power module also
does not deactivate it. Only a failed module lookup clears active; no path
sets active. Test order matters: do not perform a module lookup on the two
earlier rejection paths. No float operations, direct RNG or cooldown update.
