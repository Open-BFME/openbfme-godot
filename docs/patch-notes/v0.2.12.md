# Open BFME — alpha v0.2.12

Builders no longer get stuck next to a new foundation, and castle maps stop
listing their AI libraries as a gap. Everything from v0.2.9–v0.2.11 is in.

## How to start it — read this first

**Double-click `run-with-log.bat`.** Not `OpenBFME.exe`.

This build does not find its own content packs; the .bat points it at the ones
in this folder.

## Builders start building from the foundation's edge

A builder ordered to construct counted as "arrived" only within two units of
the site's centre. When its path ended at the centre, it walked straight into
the new foundation's footprint, pressed against it, and stood there forever
with the order still armed — an Angmar porter sent to raise a second fortress
stopped 5 units short and never began. Arrival is now the foundation's edge,
the way retail porters build.

## Castle maps: AI libraries are no longer a named gap

With map scripts running again (v0.2.11), every castle map's composed AI
libraries install and execute, so the lobby tooltip and the in-match gap list
drop `skirmish-ai-libraries`. Walkable walls, defendable gates, garrisons and
wall-mounted defenses remain named per map.

## Known gaps

- Hotkeys on W/A/S/D/Q/E/F/H/Z are reserved by camera and order actions.
- Minas Tirith's main gate still does not open a route (Q64b); Minas
  wall-mounted defenses are not buildable (importer `KindOf` gap).
- Multiplayer: a saved hero built against an older pack is strictly refused in
  lockstep after every recook.
