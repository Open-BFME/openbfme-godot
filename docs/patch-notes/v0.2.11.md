# Open BFME — alpha v0.2.11

Your custom hero speaks. v0.2.10's HUD and setup-screen fixes are included.

## How to start it — read this first

**Double-click `run-with-log.bat`.** Not `OpenBFME.exe`.

This build does not find its own content packs; the .bat points it at the ones
in this folder.

## Created heroes have their voices

A Create-a-Hero hero takes its voice set from its class (`HeroWestMale*`,
`HeroWizard*`, `HeroDwarf*` and the rest, exactly as retail's
`createaheroaudio.inc` assigns them). Two things kept every custom hero mute:
the content cook never converted those voice sets because no ordinary unit
references them, and the game collected each unit's voice requests before it
had read the unit documents, so a created hero's lines were never even asked
for. Both are fixed; the seven announcer packs now carry all ten class voice
families (the Men pack grew from 267 to 595 voice samples) and a created hero
binds select/move/attack lines like any retail hero.

## Known gaps

- Hotkeys on W/A/S/D/Q/E/F/H/Z are reserved by camera and order actions.
- Minas Tirith's main gate still does not open a route (Q64b); Minas
  wall-mounted defenses are not buildable (importer `KindOf` gap).
- Conditional bow/mounted voice variants for created heroes are not compiled
  (the unconditional class set is used).
- Multiplayer: a saved hero built against an older pack is strictly refused in
  lockstep after every recook.
