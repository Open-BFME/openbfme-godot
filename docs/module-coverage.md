# Module coverage (base-game data vs. the runtime registry)

Generated by `tools/rw_object_model/module_coverage.py` from the census module histogram (`census/census.json`, 4634 templates, 245 module classes used) and the registry table that `engine/tests/test_module_coverage.cpp` writes (`OPENBFME_MODULE_COVERAGE_OUT`).

Status:
- **ported**: a runtime class is bound in ModuleFactory (it may still report stops for parts it does not port); a Draw class counts as ported when the W3D draw runtime draws it (or, like retail's release build, draws nothing);
- **base AI**: an AI module class that runs as the base AIUpdateInterface, its own behaviour not ported (S-222);
- **parsed only**: the module data is typed (fields parsed) but the runtime is the explicit UnportedModule (S-140);
- **missing**: raw data and the UnportedModule (or an effect draw that is not drawn, S-113).
