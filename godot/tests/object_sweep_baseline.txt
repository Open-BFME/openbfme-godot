#   spelling, e.g. compiledtextures\ci\cinmrdbnr01.jpg, kb\kbmain2_nrm.tga, tclif_mor02nrm.dds) are not retail aliases and are not used.
#   "None" is the literal texture name `None`.

#   "Art\Terrain\") reads that folder; the file name builder a model texture goes through never does, so retail leaves these two
